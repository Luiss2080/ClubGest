# Instrucciones de Diseño UI/UX
- **Estética Premium:** Usar obligatoriamente una paleta de colores coherente y moderna, tipografías contemporáneas (Google Fonts), manejo sutil de sombras, espaciado uniforme y esquinas estilizadas.
- **Micro-interacciones:** Implementar estados dinámicos (*Hover*, *Active*, *Focus*) para todos los elementos interactivos con transiciones suaves (ej. `transition-all duration-300`).
- **Feedback Visual:** Uso riguroso de *Skeleton Loaders* y/o *Spinners* durante peticiones asíncronas de datos. Proveer notificaciones interactivas (Toasts/Alerts) tras cada acción relevante del usuario.
- **Responsividad y Accesibilidad:** Diseño bajo enfoque "Mobile First". La interfaz debe adaptarse impecablemente a todos los tamaños de pantalla. Preservar un contraste adecuado de texto y etiquetas semánticas (a11y).
